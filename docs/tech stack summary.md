##  Recommended Technology Stack
 
| Layer | Recommended Technology |
|---|---|
| Frontend (mobile + web) | React Native (+ React Native Web for browser support) |
| Backend API | Node.js + Express (REST + Socket.io for real-time) |
| Primary database | Firebase Firestore + Realtime Database |
| Secondary/analytics database | PostgreSQL |
| Authentication | Firebase Authentication |
| On-device AI | TensorFlow Lite |
| Cloud AI fallback | Cloud-hosted model service (e.g. Vertex AI / custom FastAPI microservice) |
| Caching | Redis |
| Media storage | Firebase Cloud Storage |
| CI/CD | GitHub Actions |
